# TFS-MSE-AutomationInfrastructure
 Tool sets used for the MSE Automation Project

 A word document has been included which presents an overall view of this environment, 
 how to set up the repository, how each device will be set up and configured, and 
 how to implement the various functions within the environment to obtain as much 
 OT control as we can in an automated fashion.
 
 This is designed to be a suite of functions that are used within an OT environment 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 that purposely does not have direct access to the business network or Internet.   As such, it receives its code from its own repository located in an Industrial DMZ and will conform to GxP standards.   This means that changes will be few and far between.  As such, the functions inside of our module will be very single purposed.   Externalized scripts will be used that in-turn utilize the functions from the module.   Becuase it is assumed that all of these functions are able to work together, they deviate from the normal verb-noun system that is common witin PowerShell scripts and instead will use a format of verb-MSEnoun.   The reason for this is that each function can now make an assumption that certain global variables will be in place.  This will horrify purists.   The reason is that it will make things like performing functions with logging, Windows events and central SQL database access much simpler through the use of Global configuration variables.  Functions and scripts that are meant to be stand-alone entities will not have teh MSE mnoniker in the name.
